# Projeto CRUD de Amigos – Programação Web II

## Sobre o projeto

Este projeto foi desenvolvido como atividade final da disciplina de Programação Web II.

A aplicação consiste em um sistema de cadastro e gerenciamento de amigos, utilizando um sistema de login para controle de acesso.

## Funcionalidades

- Sistema de login
- Cadastro de amigos
- Consulta de amigos
- Alteração de dados
- Exclusão de registros
- Integração com banco de dados MySQL

## CRUD

O sistema utiliza as quatro operações básicas de manipulação de dados:

- **Create:** cadastro de novos amigos
- **Read:** consulta dos amigos cadastrados
- **Update:** alteração dos dados
- **Delete:** exclusão de registros

## Tecnologias utilizadas

- HTML
- CSS
- PHP
- MySQL
- SQL
- XAMPP
- phpMyAdmin

## Estrutura do projeto

O projeto está organizado em arquivos responsáveis pelo login, cadastro, consulta, alteração e exclusão dos registros.

## Apresentação

A apresentação do projeto está disponível na pasta `apresentacao`.

## Objetivo

Demonstrar, na prática, os conhecimentos adquiridos em Programação Web II, incluindo desenvolvimento web, programação PHP, banco de dados e operações CRUD.
